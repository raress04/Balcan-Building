# Balcan Building - React App

## Run locally

1. Open a terminal in `balcan-building-react`
2. Install deps:
   - npm install
3. Start dev server:
   - npm run dev
4. Open the URL printed by Vite (usually `http://localhost:5173`)

## Build for production
 - npm run build
 - npm run preview

## Add images
Place assets in `public/images`. For provider logos, add 1:1 images in `public/images/providers/` (e.g. `provider-1.png`).

## Notes
- The site branding uses “Balcan Building”.
- Sections: Hero, About, Services, Portfolio, Providers, Contact, Footer.
- The header highlights the active section and supports a mobile menu.
